WELCOME SCREEN IMAGE
====================

Save your "Match & Attack" hero image in THIS folder with the name:

    welcome.png

Full path:
    assets/welcome.png

(If your file is a JPG, you can name it  welcome.jpg  instead — the game
tries welcome.png first, then welcome.jpg.)

Once the file is here, reload the game and it appears on the first screen,
with animated sparkles and a slow gentle zoom, and the "Start Game" button
on top. If no image is found, a simple text logo shows as a fallback.

Recommended: a wide image (roughly 16:9, e.g. 1920x1080) so it fills a
projector screen without cropping the logo.
